SnipVault Privacy Policy

Last updated: September 2026

Your data stays on your device

SnipVault is local-first. Your snippets, folders, and tags are stored only in a database on this device. There are no accounts, no sign-in, and no cloud sync.

No analytics, no ads, no tracking

SnipVault collects no usage data, contains no advertising SDKs, and performs no tracking of any kind. The app makes no network requests.

Backup is yours to control

JSON import/export (a Pro feature) writes a backup file only where you choose, through the system file picker. SnipVault never uploads your data anywhere.

Purchases

The optional one-time Pro unlock ($4.99) is processed by the Samsung Galaxy Store (via RevenueCat). Payment information is handled by the store; SnipVault never sees or stores it.

Permissions

SnipVault requests no special permissions. Copying snippets uses the system clipboard only at the moment you tap copy.

Children

SnipVault is a general-purpose utility and is not directed at children under 13. Because no data ever leaves the device, there is no children's data to collect.

Changes

If this policy changes, the updated version will ship inside the app with the new release.
